# השביל

משחק השיח של מפגש 3 ב"טיול משפחתי": מסך אחד שעובר מיד ליד, קובייה עם שש חפיסות של משפטים פתוחים, ולוח שבו המשפחה הולכת ביחד מהבית עד המדורה. עזר למפגש בנוכחות מטפל/ת.

**הכתובת החיה: https://yanivlein.github.io/hashvil/**

מקור האמת: אפיון 14 (גרסה 1.1) ותוצרי העיצוב ב-`design/trail/` של תיקיית הפרויקט. החלטות שלא הוכרעו שם: [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md).

## איך מעדכנים

דחיפה ל-`main` = פרסום. GitHub Actions (`.github/workflows/deploy.yml`) מריץ `npm ci`, את הבדיקות ואת `npm run build`, ומפרסם את `dist/` ל-GitHub Pages. אחרי דקה-שתיים הגרסה באוויר; טלפון שכבר פתח את האתר מקבל אותה בפתיחה הבאה.

- **לשנות נוסח או קלף:** `src/content/content.trail.he.json` בלבד (אפשר לערוך ישר ב-GitHub). `[שם]` מוחלף בשם הדמות שנבחרה. `when: "reserve"` = רק כשהורה שירת; `when: "sirens"` = רק כשהיו אזעקות; `parent` = נוסח נפרד להורה; `text` עם `father` / `mother` / `both` = שלושה נוסחים לפי S0.
- **לפתח מקומית:** `npm install`, ואז `npm run dev` (http://localhost:5173/hashvil/). `npm test` לבדיקות, `npm run build` לבנייה.

## מה בפנים

| | |
|---|---|
| מחסנית | Vite + Preact + TypeScript, כמו הכפתור. `base: '/hashvil/'` |
| נכסים | `public/assets/`: הלוח, שש הדמויות, המדורה הדולקת והאייקונים, כמו שהם מ-`assets/`. הנקודות: `src/data/trail-points.json`, `src/data/board-layout.json` |
| עיצוב | הטוקנים והגופן Assistant מ-`design/trail/` (`src/styles/tokens.css`, `trail-tokens.css`, `src/fonts/`); הרכיבים ב-`src/styles/app.css` |
| מנוע התור | `src/engine.ts`: סבבים, "לא פעמיים בסבב", טריפה, סינון לפי S0, "קלף אחר", "בוחר/ת לא לענות" = "סיימתי" |
| הלוח | `src/board.ts` (גאומטריה), `src/components/Board.tsx` (אבנים, דמויות, הילה, קפיצה והליכה, מדורה) |
| פרטיות | מצב המשחק ב-sessionStorage בלבד; "לסיים" מוחק הכול. בלי שרת, בלי חשבון, בלי אנליטיקס, בלי שום קריאת רשת אחרי הטעינה הראשונה (Service Worker שמטמין את כל 24 הקבצים) |
| בדיקות | `tests/engine.test.ts`: סינון לפי תנאים, כלל ההעברה, מספר האבנים והגעה למדורה בתור האחרון, שאין סוגר מרובע בשום טקסט, נוסחי ההורה ששירת |
